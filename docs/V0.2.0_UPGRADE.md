# v0.2.0 Upgrade Gate

This release hardens the first financial vertical slice rather than expanding autonomy.

## Added
- Durable SQLite control-plane store plus PostgreSQL production migration shape.
- Tamper-evident hash-chained audit log persistence.
- Idempotency keys for replay-safe ingestion.
- Normalized Gmail and Microsoft 365 webhook contracts.
- Local document extraction/classification for text, DOCX, XLSX and text PDFs (scans fail closed).
- Approval read/mutate API and minimal human approval web UI.
- ERPNext submit requires an approved status **and** approver identity.
- Adversarial project-resolution evaluation harness and dataset.

## Explicitly deferred
Payroll execution, autonomous payments, outbound commitments, unrestricted tools, graph database, and learned skills remain outside this gate.
