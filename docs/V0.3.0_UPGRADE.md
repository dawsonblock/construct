# v0.3.0 Upgrade Gate

v0.3.0 turns the v0.2 control plane into a deployment-shaped invoice intelligence system without expanding the financial authority boundary.

## Added
- Production `PostgresStore` with migration-driven objects, evidence, approval packets, idempotency and chained audit state.
- Gmail REST and Microsoft Graph read connectors that fetch real message bodies and attachment metadata when OAuth bearer tokens are supplied.
- Content-addressed attachment ingestion and object storage adapter.
- Rich PDF/XLSX/DOCX extraction with table preservation and explicit scanned-PDF fallback warnings.
- Conservative deterministic invoice extractor schema.
- ERPNext exact-first PO and supplier-quotation evidence resolver.
- Evidence-rich approval packets retrievable separately from mutable approval status.
- End-to-end invoice pipeline coordinator.
- Deterministic 300-case adversarial project-resolution benchmark plus scalable generator.

## Deliberately not added
- Automatic payment or payroll execution.
- OCR/vision service credentials or model-specific calls.
- Autonomous outbound email.
- Graph database.
- Free-form LLM authority over accounting facts.

## Production boundary
Set `DATABASE_URL=postgresql://...` and optionally `AUTO_MIGRATE=1`. Without it the API uses SQLite only for development/testing.
